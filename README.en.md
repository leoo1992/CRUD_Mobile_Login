# React Native CRUD Login

A mobile study project for practicing user CRUD operations with React Native. The application uses Context API and a reducer to manage state.

## Stack
- React Native
- JavaScript / TypeScript
- Context API and Reducer

## Run
Install dependencies and start the Expo/React Native development environment:

```bash
npm install
npm start
```

Run on Android or iOS after configuring the corresponding native development environment:

```bash
npm run android
npm run ios
```
